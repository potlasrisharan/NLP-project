# Multilingual Text Intelligence — NLP Project

**Project focus:** Hindi–English code-mixed text processing and token-level language identification.

This repository contains a Google Colab notebook that builds a lightweight NLP baseline using the COMI-LINGUA Language Identification (LID) dataset.

## Run the demo in Google Colab

1. Open the notebook: [Hinglish Token-Level Language Detection](notebooks/Hinglish_Token_Level_Language_Detection_Colab.ipynb).
2. Click **Open in Colab** or download the notebook and upload it at https://colab.research.google.com/.
3. In Colab, choose **Runtime → Run all**.
4. Allow the dataset and Python libraries to download.
5. When the final cell runs, open the temporary Gradio link.
6. Enter Hindi, English or Hinglish text and click **Analyze text**.

A CPU runtime is sufficient for this lightweight baseline. The notebook samples up to 10,000 training sentences and 2,000 test sentences; reduce these constants in the notebook if the session is slow.

## What the notebook implements

- Loads the COMI-LINGUA dataset's `LID` configuration.
- Parses the three annotator columns and builds majority-vote token labels.
- Creates character n-gram TF-IDF features using each token and its local context.
- Trains an SGD logistic classifier for Hindi (`hi`), English (`en`) and Other (`ot`).
- Reports macro-F1, precision, recall and a confusion matrix on the held-out test subset.
- Launches a Gradio interface for live token-level predictions.

## Important scope note

This is a lightweight baseline implementation for the college project demonstration. It is **not** the 8B-parameter COMI-LINGUA model and does not claim to reproduce the research paper's reported results. Scores are generated by the notebook at runtime.

The model score displayed for each token is a classifier score and is not guaranteed to be a calibrated probability.
